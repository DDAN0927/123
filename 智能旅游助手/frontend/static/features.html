智能行程规划

调度中心把任务交给最合适的顾问，生成一份松紧得宜的每日路线。

  • ✓ 适配天数、人数与偏好的自动编排
  • ✓ 景点、美食、交通多维度协同
  • ✓ 结合实时天气与预算，方案可执行
  • ✓ 随手调整，方案即刻更新
03 · MAP

城市地图

覆盖 355 座城市的 1500+ 个景点、美食街与地标，按拼音首字母分组挑选，位置与路线一目了然。

  • ✓ 355 城 · 1500+ 景点，按拼音首字母分组
  • ✓ 景点可自己添加 / 删除，本地保存、随时恢复默认
  • ✓ 自然语言筛选（如「带孩子」「找小吃夜市」）+ 驾车/步行/公交路线

  • ✓ 出行时间最优估算
  • ✓ 站点与路线清晰提示
